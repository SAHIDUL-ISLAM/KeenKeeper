# KeenKeeper

KeenKeeper is a small web app. It keeps track of the people  and lets you log every call, text and video chat in one tap.

## 🚀 Technologies Used

- Next.js
- React
- Tailwind CSS
- daisyUI
- Recharts
- React Hot Toast
- React Icons
- JSON file

## ✨ Key Features

- **Friends at a glance** — Cards show each friend's photo, name, tags and a colour-coded status (overdue, almost due, on-track).
- **One-tap check-ins** — Tap Call, Text or Video to log it on your Timeline and get a toast notification
- **Timeline and analytics** — Filter your history by interaction type and see a pie chart of how you stay in touch.
